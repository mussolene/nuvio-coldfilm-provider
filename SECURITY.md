# Безопасность

Не публикуйте сведения об уязвимости в открытом issue, если они содержат данные,
которые позволяют навредить пользователям. Используйте раздел Security Advisories
репозитория GitHub.

Провайдер не принимает логины, пароли и токены пользователя. Ключ TMDB предоставляет
сама сборка Nuvio во время выполнения. Он не включается в исходный код, манифест или
собранный файл провайдера.

Перед публикацией новой версии выполняются тесты, повторная сборка `dist` и поиск
локальных адресов, ключей и учетных данных в отслеживаемых файлах.
