# ColdFilm для Nuvio

[![Проверка](https://github.com/mussolene/nuvio-coldfilm-provider/actions/workflows/check.yml/badge.svg)](https://github.com/mussolene/nuvio-coldfilm-provider/actions/workflows/check.yml)
[![Лицензия MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Провайдер для полной сборки Nuvio. Он получает русское название по TMDB, ищет общедоступную страницу ColdFilm и передает найденные варианты штатному проигрывателю Nuvio. Версии 1080p, 720p и 400p из опубликованных torrent-файлов открываются через встроенный P2P-модуль Nuvio. Прямые MP4-потоки 720p и 360p остаются отдельными вариантами.

Провайдер не обходит авторизацию, DRM или ограничения доступа. Он использует только ссылки и torrent-файлы, опубликованные на открытой странице сайта. Работоспособность зависит от разметки ColdFilm, наличия раздающих и доступности TMDB, ColdFilm и видеосервера через текущую сеть или VPN.

## Проверка и сборка

```bash
npm test
npm run build
```

## Установка

Добавьте в разделе плагинов Nuvio адрес репозитория:

```text
https://raw.githubusercontent.com/mussolene/nuvio-coldfilm-provider/main/dist/manifest.json
```

После установки компьютер или отдельный сервер не нужен. Nuvio загружает обновления напрямую из GitHub, когда в манифесте появляется новая версия.

## Безопасность и ограничения

- Провайдер не принимает и не хранит учетные данные.
- Запросы отправляются только в TMDB, ColdFilm и на адреса опубликованных ими видео и torrent-файлов.
- Работоспособность зависит от разметки внешнего сайта, доступности сети и наличия раздающих.
- Проект не связан с Nuvio, ColdFilm или владельцами внешних источников.

Порядок сообщения об уязвимостях описан в [SECURITY.md](SECURITY.md).
